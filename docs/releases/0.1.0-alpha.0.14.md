# ProvenLoop 0.1.0-alpha.0.14

Date: 2026-09-09. Channel: Windows Design Partner Preview.

This release adds a lightweight graphical viewer to the existing CLI. Run
`provenloop ui` to browse local knowledge and trace its captured evidence,
learning proposals, verification receipts, feedback, and recorded use.

## Install or upgrade

```powershell
irm https://raw.githubusercontent.com/cubika/ProvenLoop/v0.1.0-alpha.0.14/install.ps1 | iex
provenloop ui
```

The installer verifies the exact GitHub Release tarball and SHA-256 sidecar.
This preview is distributed through GitHub Releases, without public npm publication.

The viewer opens the default browser and prints its local address. Keep the
terminal running while browsing; Ctrl+C stops it. Run `provenloop ui` again
after shutdown and use its new URL. An old tab cannot reconnect to a stopped
server. Use `--no-open`, `--port`, or `--data-root` when needed.

## What changed

- Added Overview, Knowledge, Activity, Work episodes, Learning, and Usage pages.
  Lists support pagination and relevant text, state, scope, or session filters.
- Added evidence navigation with retained source quotations, event content,
  capture limits, recovery receipts, conflicts, feedback, and recent usage.
  Missing sources stay explicit; stored state does not authorize task delivery.
- Added a read-only canonical SQLite reader that checks schema compatibility,
  deletion history, restore barriers, and enrichment provenance. Short request
  leases coordinate with upgrade and restore without holding a database open.
- Kept the server local to `127.0.0.1` with a random access path, origin/host
  checks, read-only HTTP methods, no external assets or browser scripts, escaped
  content, display redaction, and disabled caching. No new dependencies were added.

## Compatibility and limits

Schema remains 14. This release retains 0.13's Windows upgrade recovery and
0.12's opt-in correction and agent learning. Upgrades preserve capability
settings and learning consent. Old Copilot tools may need a new session or
host-supported reload after upgrade.

The viewer does not initialize or migrate storage, rebuild indexes, run learning,
or change knowledge. SQLite may create WAL/shared-memory coordination files.
Lists show 40 records per page; related detail sections show up to 100 records.
Refresh to read a new snapshot. All timestamps use UTC.

Usage observations distinguish guidance provided from explicit adoption. They
do not establish task success or productivity benefit. M0/MVP remain No-Go for
quality release; `0.1.0-alpha.1` remains an unapproved target.

## Validation

The release workflow runs lint, type checking, the full unit and integration
suites, packed-artifact installation/upgrade verification, and the Windows
PowerShell 5.1 installer dry run before publishing. Viewer regression coverage
includes browsing, search, pagination, HTML escaping, secret redaction, request
isolation, deletion/restore/upgrade barriers, enrichment integrity, and the built
CLI startup path.
